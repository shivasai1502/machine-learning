# Foundations - Python for Machine Learning

Welcome to the foundations section! This is where your ML journey begins.

## Why These Libraries?

Machine learning in Python is built on three core libraries:
- **NumPy**: Numerical computing and array operations
- **Pandas**: Data manipulation and analysis
- **Matplotlib**: Data visualization

Master these, and you'll understand 80% of ML code you encounter!

## Learning Order

1. **Start with NumPy** - It's the foundation of everything
2. **Move to Pandas** - Learn data manipulation
3. **Finish with Matplotlib** - Visualize your results

## What You'll Learn

### 03_matplotlib_basics.py
